CARD VAULT USER GUIDE

Complete guide to managing your graded card inventory, tracking prices, and identifying the best cards to buy and sell.

Initial Setup
One-time steps — takes about 10 minutes total

Your App URL

Card Vault lives at: justinnymark.github.io/cardvault/

Bookmark it on every device. On iPhone: tap the share icon → Add to Home Screen for a native app icon.

Anthropic API Key

Powers all AI features — photo card identification and price searching. Entered once per device.

1
Go to console.anthropic.com
Sign in with your existing account.
2
Click API Keys → Create Key
Name it anything (e.g. "Card Vault"). Copy the key — it starts with sk-ant- and you only see it once.
3
Paste into the Card Vault setup screen
The app tests the connection automatically before saving.
Cost: Scanning 100 card photos ≈ $0.10. Price refresh on 300 cards ≈ $0.30–0.50. Billed monthly to your Anthropic account — separate from your Claude.ai subscription. Use claude-sonnet-4-6 (current model) — Opus is 5× more expensive with no quality benefit for this use case.
Privacy: Your API key is stored only on your device. It is never synced to Supabase or stored anywhere else.
Cross-Device Sync (Supabase)
Your inventory stays identical on Mac, iPhone, and any device with the link

Card Vault uses Supabase as a free cloud database. Add a card on your Mac and it appears on your phone instantly.

One-Time Supabase Setup

1
Go to supabase.com → Sign up free
Use GitHub login or email. No credit card. Free tier is more than enough for 300+ cards.
2
Create a new project named "card-vault"
Choose US East region. Set a database password and save it. Wait ~2 minutes to provision.
3
Run this SQL to create your tables
Click SQL Editor in the left sidebar, paste the SQL below, and click Run.
create table cards (
  id text primary key,
  profile text not null,
  data jsonb not null,
  updated_at timestamp default now()
);

create table watchlist (
  id text primary key,
  profile text not null,
  data jsonb not null,
  updated_at timestamp default now()
);

-- Enable RLS with anon access policy
alter table cards enable row level security;
alter table watchlist enable row level security;

create policy "anon full access" on cards
  for all using (true) with check (true);

create policy "anon full access" on watchlist
  for all using (true) with check (true);
4
Get your credentials
Go to Project Settings → API Keys → Legacy anon, service_role API keys. Your Project URL is https://[your-project-id].supabase.co — build it from your Project ID shown on the General page. Copy the anon public key (starts with eyJ). Never use the service_role key in the app.
5
Enter both keys in Card Vault setup
The setup screen has two sections — Anthropic and Supabase. Enter both and tap Save & Get Started. The app tests both connections.
6
Repeat on every device
Enter the same Supabase credentials on each device. Data syncs automatically from that point on.
Anthropic key vs Supabase key: The Anthropic key is device-specific (stored locally only). The Supabase keys are the same on every device — they point to your shared database.
Important: Settings → Reset All Keys clears credentials on that device only. Your data in Supabase is always safe. Re-enter all three keys after resetting.
Dad & Lad Profiles
Two completely separate collections on one app

The opening screen lets you choose Dad or Lad. Each profile shows how many cards are in inventory and how many have been sold. All data is fully siloed — nothing crosses between profiles.

👁 Browsing Each Other's Collection

Both profiles can view each other's collection in read-only mode. Tap Lad's (or Dad's) in the nav. You can search and filter but cannot edit or add cards.

🔄 Switching Profiles

Tap your profile badge (D or L) in the top-right corner of the nav to return to the profile selector.

Adding Cards by Photo
The fastest way — one card or a whole pile at once

Make sure you are in BUY mode, then tap + Add Card from either the Home dashboard or My Cards screen.

1
Select the 📷 Photo tab and upload a photo
Tap the upload area to choose from your camera roll or take a photo directly. One card or a full pile both work.
2
Tap "Identify Cards"
The AI reads every PSA/BGS/SGC/CGC label — player name, year, brand, set, grade, cert number, RC/Auto/Patch flags, and BGS subgrades.
3
Review the identified cards
Each card shows a grade badge and cert number prominently. Check these against your physical cards. If anything is wrong, tap "✏ Correct grade or cert # if wrong" to expand inline correction fields for that card.
4
Enter purchase info for each card
Each card gets its own price, date, and source. Fill in what you paid individually — no more shared prices for bulk photos.
5
Tap "Add X Cards"
All cards are added to your inventory in one tap.

When the Photo Isn't Clear Enough

The AI will flag uncertain fields rather than guess. If a cert number or grade cannot be confidently read, you'll see an amber ⚠ Photo not clear enough to read: certNumber warning on that card. The correction section automatically expands so you can enter the correct value manually — or clear the photo and retake a clearer one.

A wrong cert number is worse than no cert number. The AI is instructed never to fabricate cert numbers — null is always better than wrong.

Photo Tips for Best Results

  • Lay cards flat on a solid background with the label clearly visible
  • Bright, even lighting — avoid glare on the slab
  • For bulk photos of similar cards (e.g. multiple Messi cards), make sure each label is readable individually
  • The closer and clearer the label, the more accurate the cert number reading
  • BGS cert numbers are in the barcode area at the bottom — make sure that area is in frame
Adding Cards Manually
Use when photo ID isn't producing clean results

Tap + Add Card → select the 📝 Manual tab. Fill in all fields and tap Add Card. Player name and grade are required — all other fields are optional but recommended.

Duplicate Detection
Card Vault prevents accidental double-entries

Every time you add a card (photo or manual), the app checks your existing inventory for duplicates using cert number as the primary match. If both cards have cert numbers and they differ, they are treated as different cards regardless of player/grade match.

DUPLICATE — BLOCKED Already in active inventory

If the card is already in your active inventory, it is blocked entirely and will not be added. You'll see a red warning on that card in the identification screen.

PREVIOUSLY SOLD Matches a sold card

If the card matches something in your sold history, a soft warning appears: "You previously sold this card on [date] for $[amount]. Are you buying it back?" Tap Yes, Add It to confirm or No, Skip to skip that card.

Bulk Price Update

Tap ✏ Bulk Price on the My Cards screen to enter last sale prices for multiple cards at once. Useful after checking Card Ladder manually. Leave any card blank to skip it.

Morning Price Refresh
Automated price lookup across eBay sold listings and auction houses

From the Home dashboard, tap Run Refresh. The app searches eBay completed listings, PWCC, and Goldin for recent sold prices on every active card. Updates Last Sale price, calculates P&L, and sets alert status automatically.

Date protection: If you've manually entered a last sale price, the refresh only overwrites it if it finds a more recent sale. Your manual entries are always protected from older auto data.
Note on 130point: 130point has bot protection that blocks automated searches. Use the 🔍 View on 130point link inside each card's detail view for manual research instead.
Sell Recommendations
Your ranked list of cards to move — updated in real time

Tap Sell Now in the nav. Cards are ranked by a score combining ROI %, alert status, and margin. Answers: "If I'm going to a show tomorrow, which cards do I bring?"

🟢 Sell Now

Strong sell signal — 25%+ ROI with meaningful dollar gain. These cards are at or near peak.

⚡ Consider Selling

10–24% ROI — worth listing or bringing to your next show.

⏳ Hold

Profitable but not at a sell threshold yet.

🔴 Underwater

Last sale below cost. Know your losses before a show.

Run the Morning Refresh before checking this screen — recommendations are only as good as the price data behind them.
Selling Cards
Single cards, bulk sells, and cards not in your inventory

Selling a Single Card

Switch to SELL mode. In My Cards, a red Sell button appears on each in-inventory card. Enter the sale price and date, confirm. P&L shows instantly.

Bulk Sell at a Show (Photo)

1
Switch to Sell mode and tap − Sell Card
Upload a photo of all the cards you just sold.
2
Tap Identify Cards
The AI matches each card to your inventory using cert number first, then player name.
3
Review matches and enter sale price
Check/uncheck which cards were sold. Enter total sale price and date, then tap Mark Sold.

Selling a Card Not in Your Inventory

If an identified card isn't found in your inventory, it shows "Not in inventory" with a red border. Two options appear:

  • + Add & Sell — adds the card to inventory (you enter what you paid, or $0 if unknown) and immediately marks it sold. Keeps your records complete.
  • Leave as-is to skip — does nothing with that card.
Watchlist
Track cards you're thinking about buying

Tap Watchlist in the nav. Add cards you're considering buying with an optional target buy price.

Tap 🔄 on any item to look up recent sold prices. The app returns Last Sale, Avg Recent, Lowest Ask, and a Good Buy / Fair / Overpriced verdict. If a card hits or drops below your target, it's flagged with a green 🎯 AT OR BELOW TARGET banner.

Tap 🔄 Check All to refresh every watchlist item at once.

Gain & Loss Calculations
How the numbers are calculated
MetricCalculationWhere shown
Unrealized G/L(Market Value − Purchase Price) for cards In Inventory. "Paper" gain — what you'd make if you sold today.Dashboard, each card
Realized G/L(Sale Price − Purchase Price) for Sold cards. Actual profit you've made.Dashboard, sold card detail
Simple ROI %(Profit ÷ Cost) × 100. Quick comparison between cards.Each card, Sell Now screen, CSV
Annualized ROI %((1 + Simple ROI) ^ (365 ÷ Days Held) − 1) × 100. Normalizes performance to a yearly rate like a stock return.Internal CSV export
Days HeldPurchase date to sale date (or today for active cards).Internal CSV export
Market ValueBest available: 7-day avg if exists → 30-day avg → last sale regardless of age.Buyer CSV export
Price Alerts
Thresholds and what they mean
AlertConditionAction
Urgent SaleLast sale ≥25% above cost AND gain >$25Strong sell signal — market may be at peak
Time to SellLast sale 10–24% above cost AND gain >$25Worth listing or bringing to next show
NormalEverything elseHold or no data
The $25 minimum gain floor prevents noise — a $10 card jumping 30% is a $3 gain, not worth your effort. Both alert levels require a meaningful dollar gain to fire.
Manual Price Updates
Enter prices from Card Ladder or any other source

Open any card's detail view (tap View) and scroll to Manual Last Sale Update. Enter the price and date, tap Save Last Sale Price.

The morning refresh only overwrites your manual entry if it finds a more recent sale date — your data is always protected.

The 🔍 View on 130point link at the bottom of every card detail opens 130point pre-searched for that exact card. After passing the one-time bot check, you can see full sales history across eBay, Goldin, Heritage, PWCC, Fanatics, and Alt.

Bulk Price Update
Update multiple cards at once from the My Cards screen

Tap ✏ Bulk Price on the My Cards screen. Every active card appears in a list. Enter last sale prices and dates for as many as you want — leave others blank to skip. Tap Save All Prices. Fastest way to catch up after checking Card Ladder.

Updating the App
How to deploy new versions from Claude

Every update from Claude includes both index.html and guide.html — upload both together so they're always in sync.

1
Download both files from Claude
Tap each file attachment and download to your computer.
2
Go to github.com/justinnymark/cardvault
Sign in and open your cardvault repository.
3
Delete the old file
Click index.html → trash/delete icon → Commit changes. Repeat for guide.html.
4
Upload new files
Click Add file → Upload files → drag both files in → Commit changes.
5
Hard refresh
Wait 60 seconds for GitHub to deploy. Then press Cmd + Shift + R (Mac) or Ctrl + Shift + R (Windows).
Your card data is in Supabase — it is NOT in the GitHub files. Updating the app never touches your inventory data.

Starting a New Development Session

Always start a fresh Claude conversation to avoid hitting usage limits. Say: "Continuing Card Vault development — here is the current index.html" and attach the file. Claude picks up exactly where you left off.

Troubleshooting
Common issues and fixes
🔲 App shows blank white screen

Hard refresh: Cmd + Shift + R (Mac) or Ctrl + Shift + R (Windows). If still blank, the uploaded file may have an error — start a new Claude conversation and ask to diagnose.

📷 Photo not identifying cards correctly

Make sure the grading label is clearly visible and in focus. For bulk photos of similar cards, each label needs to be individually readable. If cert numbers come back wrong, use the inline correction fields or retake with a clearer photo. The AI will flag fields it can't read rather than guess.

💰 Price refresh shows blank last sales

Some cards have few recent sales or the search can't find them. Use Manual Last Sale Update in the card detail view, or use Bulk Price Update after checking Card Ladder or 130point yourself.

📱 Cards don't appear on my phone

Enter your Supabase credentials on the new device. If the app shows the setup screen, enter all three keys (Anthropic + Supabase URL + anon key). If it skips to the profile selector, go to ⚙ Settings → Reset All Keys, then re-enter everything. Your data in Supabase is always safe.

🔄 Changes on one device aren't showing on another

Hard refresh on the out-of-date device (Cmd + Shift + R). Data syncs to Supabase instantly on save, but the browser may show a cached page.

📱 App looks outdated after upload

Wait 60 seconds for GitHub Pages to deploy, then hard refresh. Or try opening the URL in a private/incognito window.

💾 My cards disappeared

If Supabase is set up, your data is safe — re-enter your Supabase keys on this device (Settings → Reset All Keys). If Supabase was never configured, data was local only. The Internal Report CSV export is your backup — export regularly.

🔑 "Connection failed" on setup

Double-check the Anthropic key starts with sk-ant- and was copied fully. Check your Anthropic account has a valid payment method at console.anthropic.com. For Supabase, confirm the URL includes https:// and the anon key is the full eyJ... string.
